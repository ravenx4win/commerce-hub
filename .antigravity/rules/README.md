# Antigravity Rules Directory

This directory contains workspace rules and guidelines for this project.

## Structure

Rules are markdown files (`.md`) placed in this directory or subdirectories:

```text
rules/
├── coding-standards.md
├── testing-guidelines.md
└── architecture.md
```

## Format

Rules are written in Markdown. You can optionally include frontmatter or plain markdown instructions:

```markdown
# Coding Standards

- Use descriptive naming conventions.
- Follow established project architecture.
```
